MiniVehicle

Sổ đăng ký xe theo VIN — vòng đời kho → phân bổ đại lý → lệnh giao → giao & kích hoạt bảo hành. Chuyển đổi từ module Car (2010.HTC).

API (cần X-Api-Key + token MiniSSO)

  • POST /api/vehicles — nhập xe (VIN, Model)
  • GET /api/vehicles?status=&model=&dealer= — tra/tìm
  • POST /api/vehicles/{vin}/allocate — phân bổ đại lý
  • POST /api/delivery-orders — tạo lệnh giao (nhiều VIN)
  • POST /api/delivery-orders/{doNo}/deliver — giao + kích hoạt bảo hành
  • GET /api/vehicles/{vin}/history — lịch sử vòng đời
  • GET /api/stats — thống kê

Công khai

  • GET /api/lookup?vin= — tra cứu VIN + bảo hành (khách/đại lý)

SSO: /api/whoami. Swagger: /swagger.
